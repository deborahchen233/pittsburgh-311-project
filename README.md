# Pittsburgh 311 Service Request Analysis

## Project overview

This project examines common Pittsburgh 311 request types,
neighborhood patterns, repeated reports, and seasonal variation.

## Data source

Western Pennsylvania Regional Data Center:
https://data.wprdc.org/dataset/311-data

## Repository structure

- `notebooks/`: Data cleaning and analysis code
- `data/raw/`: Original data
- `data/clean/`: Cleaned data
- `figures/`: Final visualizations
- `report/`: Final research report

## How to reproduce the analysis

1. Install the packages in `requirements.txt`.
2. Open `notebooks/pittsburgh_311_analysis.ipynb`.
3. Run the cells in order.
